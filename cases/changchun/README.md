# 长春四环 · 完整研究案例

[返回城市案例](../README.md)

这是 Heatwater 用于验证联合筛查流程的真实城市案例。分析在长春四环边界内的 30 米采样网格进行，通过主干路与河流围合形成 51 个分析片区。

| 项目 | 内容 |
|---|---|
| 范围与坐标系 | 长春四环边界，EPSG:32651 |
| 地表温度窗口 | 2013–2015、2021–2023 年夏季 |
| 交互分析 | 热与水涝代理、建筑功能暴露、候选依据、72 组参数稳定性、核查清单导出 |
| 默认筛查 | 32 个候选片区，14 个片区在至少 80% 的参数组合下入选 |
| 交付状态 | 本地真实地图已验证，公开复现可先使用模拟输入 |

分区规则、四环裁切与结果见[长春分区方法](../../docs/planning-blocks.md)。入选规则与频率含义见[解释和稳定性](../../docs/explanation-stability.md)。输入来源、再分发状态与署名见[数据说明](../../DATA_LICENSE.md)。
