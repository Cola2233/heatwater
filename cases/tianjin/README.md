# 天津中心样区 · Landsat 地表温度

[返回城市案例](../README.md)

离线地图展示公开 Landsat 的单景地表温度。用浏览器打开后可点击 16 个规则网格，查看均值、温度范围与有效像元数，并下载 CSV。
[下载天津离线地图](https://github.com/Cola2233/heatwater/releases/download/v0.1.0/heatwater-tianjin-temperature.html)

样区为 117.14–117.25°E、39.08–39.17°N。影像对齐至 EPSG:32650 的 30 米采样网格。
