# 热水共治 UI 第三轮：Huashu × sc-datav

## 共同任务

- 面向比赛汇报、研究展示和朋友试用，主角是长春30米热水复合栅格。
- 用户明确否定上一版Carbon界面，并要求结合Huashu Design与sc-datav重新设计。
- 三版统一桌面1440×900、手机375×812；全部能离线打开并操作真实数据。
- 保留6个图层、地图缩放平移、阈值/权重、统计与导出。
- 436411有效像元、392.77平方公里；基线数值以当前Python成果校验。
- 无实时数据、无未经测量的高程、无虚构行政区或人口。
- 三版是方向初稿；不覆盖原单文件，用户选定后合并最终版。

## 六张方向卡

### 候选A：空间观测大屏（选入完整稿）
逻辑与来源：sc-datav Demo0的真实截图与panel实现；Stamen式地图主角思路。
借用：中央大地图，窄侧栏图表，深墨绿灰底，森林/铜色克制对比。
主角：真实连续复合栅格；热水联合像元密度。
骨架：左侧分区与关系图，中央地图，右侧参数/暴露。
胆量：地图占据页面中心，不再使用营销式大标题开场。
form：热、水及暴露需要被同时观察，而不是分散为长网页章节。

### 候选B：地图研究工作台（选入完整稿）
逻辑与来源：sc-datav Demo1的地图/面板关系与浅色语境，改为适合近距离阅读的桌面分析界面。
借用：地图主舞台和浮动工具，减少装饰线；白瓷色、铁锈色操作重点。
主角：真实栅格与下方的三张紧凑分析图。
骨架：左侧宽地图，右侧固定参数抽屉，下方横排分析。
胆量：首屏几乎全部用于研究操作，不做落地页式介绍。
form：研究者先选图层、试参数，再读统计与口径。

### 候选C：城市风险图谱（选入完整稿）
逻辑与来源：Giorgia Lupi式数据人文主义思路，结合sc-datav的数据联动。
借用：地图/解释同页，中文标题与数字分级，图像与统计相互指认。
主角：暗底真实地图与右侧52.87平方公里基线叙事。
骨架：左大地图，右侧阐释和参数；下方分析条带。
胆量：把一个真实判读结论作为文字主轴，而非堆满四周仪表。
form：先说明两种高值判定口径，再让读者自己调参数。

### 候选D：浅金汇报屏（备选）
逻辑与来源：sc-datav Demo1实图的暖橙主题与对称双侧图表。
借用：同屏概览、温暖中性色、地图中央留白。
主角：真实地图；不复制四川地形或假造长春山地。
骨架：对称侧栏和中央地图；与A相比更适合亮室投屏。
胆量：暖色数据大屏，避开传统蓝色驾驶舱。
form：在汇报场景同时容纳方法、地图和结论。

### 候选E：四象限数据构成（备选）
逻辑与来源：秒数44，网页池第5号Pure-CSS Art；样张已查看。
借用：由数据构成的几何比例，而非装饰插画。
主角：四类分区面积构成的矩形图与地图。
骨架：左侧数据比例主图，右侧地图。
胆量：把真实分区数量转为构图材料。
form：四象限分类的结构本身就是视觉材料。

### 候选F：中文图谱展板（备选）
逻辑与来源：秒数44，东亚池第9号田中一光几何平面；样张已查看。
借用：中文竖向标题与明确图像边界，黑/纸色结构和少量数据色。
主角：真实栅格图像、热水二维关系。
骨架：右侧短标题栏，左侧双图。
胆量：展示性排版强于工作台，仅作为汇报备选。
form：栅格与四类分区的方形几何关系。
