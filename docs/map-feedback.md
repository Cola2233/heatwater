# 地图实时反馈

调参后默认跟随图层：热权重切至复合分数，判定阈值切至治理分区。变化叠加与原始分数明确区分：

- 权重变化：橙色表示复合分数增加，青色表示减少；片区按复合均值差着色，像元按逐像元分数差着色。
- 阈值变化：橙色表示进入热涝双高，青色表示退出；片区按双高像元占比差着色。
- 未变化区域淡化。没有实际空间变化时如实提示，不生成装饰性变化。

变化基准为上一次完成计算的参数，连续拖动按动画帧合并计算。像元分数差小于1e-6仅在视觉反馈中视作零，
不影响原算法或统计。变化强度使用固定标尺：权重分数差0.1、双高占比差1达到最大显示强度，并非修改原始数值。

可取消“调参跟随图层”，此时保留原始底图并叠加变化；取消“显示本次变化”则显示当前参数结果。
“对比上一步”只切换地图与悬停数值，右侧统计仍为当前参数，界面会明确注明。
切换案例、分区尺度或手动切换图层会清除不适用的变化对比，原始观测与道路边界保持各自含义。

悬停分区会显示轮廓、复合分数、双高占比，以及本次变化值。PNG导出随当前显示模式标注图例，
变化图额外标注基准权重与阈值。

验证包括纯数值变化测试及真实/模拟案例的离线端到端检查：水分数底图不变、变化叠加可见、
自动跟随图层、上一步切换、阈值进入退出、像元模式、悬停、导出和手机宽度。
