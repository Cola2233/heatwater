# 已选 C 方向的融合实现

用户选择见项目根目录 direction-approved.md。正式网页以 C 的城市图谱为主，保留米白纸面、深色主地图、双高面积主指标与结论叙事。

从 A 引入紧凑的分区构成、热水联合分布和建筑暴露总览，从 B 引入集中的参数工具与导出操作。分析图表放在主图下方，避免抢占主地图。纯净地图模式可以隐藏右侧与下方分析，恢复时保留当前参数。

主视觉来自真实研究栅格；没有添加虚构时间序列或地形。图表由当前案例的共同有效像元计算。联合分布数量采用对数透明度映射，虚线随阈值更新；像元相关系数不表示因果关系。

维护入口为 website/index.html、style.css、charts.js、app.js。真实数据的 local.html 和单文件交付由原有导出、打包脚本生成。旧版备份位于 artifacts/ui-before-atlas/，参考初稿位于 design-demos/2026-11-02/。
